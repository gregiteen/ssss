# IDE personalization

```bash
npx total-recall connect claude-code   # CLAUDE.md
npx total-recall connect codex         # AGENTS.md
npx total-recall connect cursor        # .cursor/rules/
npx total-recall connect gemini        # GEMINI.md
```

Total Recall only writes inside managed inject markers. Your local rules stay intact.
